# Current Flux/MIP Framework — 23 July 2026

## Scientific status

The active framework is a **speculative, falsifiable laboratory model of the quantum-to-classical transition**. It is not a validated theory of objective collapse, gravity, dark matter, or cosmology.

The repository now separates three things that earlier versions mixed together:

1. standard open-system quantum dynamics;
2. a candidate record-conditioned stochastic actualisation mechanism;
3. historical cosmological, gravitational, and cross-domain models retained for provenance only.

## Active meaning of MIP

**MIP means Minimum Interface Points.**

This is an interpretive name for a hypothetical physical interface at which quantum alternatives may become registered. The current theory does **not** assume that the interface is literally Planck-sized, nor does it postulate a universal update clock. A fundamental length or timescale must be derived by a future covariant model rather than inserted by hand.

## What the numerical audits establish

The positivity-preserving trajectory work supports the following limited conclusions:

- finite-time branch locking can occur in monitored open-system models;
- positivity and state normalisation can be preserved exactly by finite-step Kraus updates;
- different record choices can produce different trajectory morphologies while reconstructing the same ensemble evolution;
- stronger branch-to-record geometry can increase the locked fraction and shorten locking time;
- ensemble branch frequencies remain compatible with the initial Born weights in the audited runs.

These are successful numerical and standard-open-system results. They are not evidence of objective collapse.

## Identifiability and degeneracy

Two results must be kept together.

1. A fast, strongly coupled, noncommuting structured bath can reproduce a nonlinear MIP-like pulse-spacing response within the tested experimental precision. Nonlinearity alone is therefore not distinctive.
2. A later local tangent-space analysis found operating points where the MIP derivative lies substantially outside the nuisance span. This establishes local identifiability in selected parameter regions, not global uniqueness.

The correct test is therefore not whether a curve looks nonlinear. It is whether one common MIP parameter set survives controlled geometry, bath, temperature, detuning, pulse, and hardware sweeps after all standard nuisance directions are included.

4. **Bath orthogonality:** one common \((\gamma_{\mathrm{MIP}},\tau_R,p,\xi)\) survives bath direction, memory, temperature, detuning, and hardware-relaxation sweeps.

The preferred four-state/phase-ladder protocol should separate even-parity dephasing from odd-parity phase shifts and preserve blinding through acquisition and fitting.
