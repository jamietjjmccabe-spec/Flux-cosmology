## Promotion rule

A branch may be promoted to the active physical framework only when it has:

1. a defined mathematical object;
2. an implementation with convergence and invariance audits;
3. a standard-physics null model;
4. an observable that is not inserted by construction;
5. an explicit falsification criterion;
6. independent reproduction data or code.
